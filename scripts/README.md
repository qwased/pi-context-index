# Scripts

本目录预留给本地开发与验收工具，**不进入 npm 包**。0.1.0 计划中的工具：

| 工具 | 阶段 | 作用 |
|---|---|---|
| 真实会话基准 | P4 | 10K 条消息 / 50MB 混合会话的冷建索引、热查询、读取与渲染耗时 |
| 固定 12 题评估 | P4 | 目标/更正 4、近期工作 3、历史数值/错误/文件 3、15K 第二窗口与 37K 深段各 1；记录来源覆盖、调用数、全文重复读取与 prompt token |
| 打包检查 | P5 | 确认 `npm pack` 只含入口、`src/**/*.ts`、README、LICENSE、CHANGELOG |
| 会话审计 | P4 | 汇总本地会话的结构指标（消息数、字段长度、编辑/分支数量、压缩次数），只输出聚合计数 |

数据边界：

- 真实会话脚本只输出聚合计数和长度；**不得打印或引用消息正文、文件名或绝对路径**。
- 需要写入文件的产物放在 git-ignored 的 `research/` 下。
- 普通自动测试使用合成夹具和临时 cwd/agentDir；真实会话检查只在 `~/.pi/agent/sessions` 存在且显式运行时执行。

脚本落地时优先用 TypeScript + Bun，与包内代码共享类型；不把实验开关带进运行路径。
